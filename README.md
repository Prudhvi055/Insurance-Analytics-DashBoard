# Insurance Analytics Dashboard

## Project Overview

This project provides an end-to-end analysis of insurance business performance using SQL, Excel, Power BI, and Tableau. The objective was to analyze policy performance, claims trends, branch revenue, account executive productivity, opportunity conversion, and budget allocation to generate actionable business insights.

---

## Business Problem

Insurance companies manage thousands of policies, claims, revenue transactions, opportunities, and customer interactions. Tracking performance across multiple branches and account executives can be challenging.

This project helps stakeholders:

- Monitor policy performance
- Analyze claims activity
- Track branch-wise revenue
- Measure account executive productivity
- Evaluate opportunity conversion
- Compare budgets against actual revenue
- Identify business growth opportunities
